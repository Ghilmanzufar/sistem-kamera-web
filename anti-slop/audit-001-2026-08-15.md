# Audit Anti-Slop: Halaman History Inspeksi Admin
Tanggal: 2026-08-15
Dokumen: `web_admin/src/pages/History.jsx` (beserta komponen pendukung `DataTable`, `StatCard`, `StatusBadge`, `PageHeader`)

---

## Ringkasan Audit
Audit ini mengevaluasi halaman Riwayat Inspeksi Admin terhadap standar antislop AI (Design, UX Craftsmanship, Copywriting, Aksesibilitas, dan Tata Letak Mobile). Ditemukan beberapa pola umum AI slop seperti excessive glassmorphism/glow, border radius seragam berlebih, kurangnya penanganan keyboard (Escape modal / focus ring), animasi berlebih pada data historis, serta grid filter yang tidak seimbang.

---

## Daftar Temuan Bernomor (Numbered Findings List)

### Priority: HIGH (Hard Gate)

1. **[R-32 / R-26] Modal Detail tidak dapat ditutup dengan tombol Keyboard `Escape` dan StatCard interaktif tidak memiliki aksesibilitas keyboard (`tabIndex`, `role="button"`, `onKeyDown`).**
   - *Alasan*: Komponen modal dan kartu filter interaktif wajib dapat diakses dan dioperasikan menggunakan keyboard tanpa ketergantungan mouse.

2. **[R-27] Ketiadaan UI State khusus saat fetch data mengalami kegagalan (Error State) dan Empty State yang kurang informatif/kontekstual.**
   - *Alasan*: Ketika request API gagal, UI hanya mengandalkan toast tanpa tampilan error state dengan tombol coba lagi (retry) pada area tabel.

3. **[R-03 / antislop-layoutmobile] Grid filter (5 elemen) pada desktop layout 4 kolom menyebabkan tombol aksi terdorong canggung ke baris baru dengan ruang kosong yang lebar.**
   - *Alasan*: Form filter harus memiliki ritme dan alignment grid yang rapi pada semua breakpoint tanpa menyisakan ruang kosong asimetris yang tidak disengaja.

4. **[R-32 / antislop-human] Tidak adanya custom visible focus indicator (`focus-visible`) pada tombol aksi dan input filter.**
   - *Alasan*: Pengguna keyboard kehilangan indikator visual posisi fokus saat bernavigasi menggunakan Tab.

---

### Priority: MEDIUM (Purpose-Gate)

5. **[R-10 / R-13 / R-12] Trend-Stacking berlebih: Glassmorphism (`backdrop-blur-md`), glow shadow (`shadow-blue-600/30`, `shadow-emerald-600/30`), dan border ganda (`border-2 border-white/10`) digunakan secara masif di semua kontainer sekaligus.**
   - *Alasan*: Efek glass dan shadow berwarna tebal di setiap kartu, tabel, filter, dan pagination merusak hierarki visual dan menjadi penanda visual AI slop.

6. **[R-09 / R-19] Status Badge pada data historis menggunakan animasi berkedip (`animate-pulse`) terus-menerus untuk status NG.**
   - *Alasan*: Animasi pulse pada tabel riwayat masa lalu menciptakan polusi visual yang mengganggu fokus operator/admin dalam membaca data.

7. **[R-01 / R-29] StatCard menggunakan gradien multi-warna bawaan template (`from-blue-500/20 to-indigo-500/5`, `from-emerald-500/20`, `from-rose-500/20`) tanpa hierarki fokus tunggal.**
   - *Alasan*: Desain dashboard industri membutuhkan palet yang solid, tegas, dan kontras tinggi untuk memudahkan pemantauan metrik kritis.

---

### Priority: LOW (Quality Locks & Copywriting)

8. **[R-11] Border radius seragam berlebihan (`rounded-3xl` dan `rounded-2xl` di seluruh elemen mulai dari tombol, modal, input, hingga badge).**
   - *Alasan*: Radius yang terlalu bulat (pill-look) di semua level merusak kesan industrial dashboard yang presisi dan profesional.

9. **[R-16 / antislop-copywriting] Inkonsistensi dan redundansi teks UI (misal: "Export CSV / Excel", "Max 15 Data / Halaman", "Tutup Informasi").**
   - *Alasan*: Teks tombol dan label harus ringkas, lugas, baku, dan sesuai konteks operasional pabrik manufaktur (misal: "Ekspor CSV", "Tutup").

10. **[R-31 / Craftsmanship C-2] Polling interval 2.5 detik berjalan tanpa indikator sinkronisasi background atau kontrol jeda saat pengguna sedang menginspeksi modal detail.**
    - *Alasan*: Refresh data di background dapat menyebabkan refetch yang tidak diinginkan saat admin sedang fokus membaca snapshot bukti NG.
